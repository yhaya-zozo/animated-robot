# Animated Robot

أداة بسيطة لأتمتة إرسال رسائل WhatsApp لعملاء شركة التصوير قبل الإيفنت.

## الفكرة
- البيانات تأتي من **Google Sheets**.
- يتم إرسال رسائل WhatsApp **قبل الإيفنت بيوم واحد (غدًا)**.
- القوالب باللغة العربية مع متغيرات مثل الاسم وتاريخ الإيفنت.

## التشغيل المبسّط
لو حابب تمشي خطوة بخطوة بدون تفاصيل تقنية، افتح:
- `automation/WORKFLOW_GUIDE.md`

## المتطلبات
- Python 3.10+
- حساب WhatsApp Business API (أو مزود مثل Twilio/360dialog).
- Google Service Account مع صلاحية قراءة Google Sheets.

## التشغيل السريع
1. انسخ ملف الإعدادات:
   ```bash
   cp .env.example .env
   ```
2. عبّي القيم داخل `.env`.
3. ثبّت الاعتماديات:
   ```bash
   pip install -r requirements.txt
   ```
4. شغّل السكربت:
   ```bash
   python automation/send_whatsapp_reminders.py
   ```

## تجربة آمنة بدون إرسال (مهم أول مرة)
- في `.env` ضع:
  ```
  DRY_RUN=true
  ```
- السكربت سيطبع الرسائل بدل إرسالها.

## شكل Google Sheet (مقترح)
| الاسم | رقم الواتساب | تاريخ الإيفنت | نوع الإيفنت | الحالة | تم الإرسال؟ | قالب الرسالة |
|------|--------------|--------------|-------------|--------|-------------|---------------|

> ملاحظة: العمود **تم الإرسال؟** يمنع إرسال الرسالة مرتين.

**ملف مثال جاهز:**
- `automation/sample_sheet.csv`

## القوالب
يمكنك تعديل القوالب في الملف: `automation/templates.json`.

## الجدولة
يمكنك تشغيل السكربت يوميًا عبر cron أو أي خدمة جدولة.
